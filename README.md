## 🧭 What is this?

**JasonLab** is one big repository that holds (almost) every program Jason has written while learning: small console programs in Python, Java and C, Android apps, Godot games, web pages, school assignments, training exercises and the Docker Compose files behind a home server.

It is a *lab*, not a polished product: some folders contain finished little programs, some are experiments, and a few are unfinished. Every folder has its own `README.md` that says what the program does, how to run it and what state it is in.

## ▶️ Running things (quick cheat sheet)

| Language | Run it with |
| --- | --- |
| Python | `python3 file.py` (some need `pip install pygame`, `opencv-python` or `rich`) |
| Java | `javac File.java && java File` (JDK 11 or newer) |
| C | `gcc file.c -o program && ./program` |
| PHP | `php -S localhost:8000` inside the folder, then open the page in a browser |
| HTML/CSS/JS | open `index.html` in a browser |
| Docker Compose | `docker compose up -d` inside the service folder (read its README first) |
| Android | open the project folder in Android Studio and press Run |
| Godot | Godot 4.4 → Import → pick the `project.godot` file |

## 🚦 Status legend used in the folder READMEs

- ✅ **Works** – runs as described
- 🚧 **Work in progress** – partly done or an experiment
- ❌ **Doesn't run yet** – has a known error that needs fixing first (the README says what)
