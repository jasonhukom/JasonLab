# Camera

> Opens your **webcam** in a window.

**Status:** ✅ Works

## ⚙️ How it works

1. Asks whether the webcam is **internal** (type `0`) or **external** (type `1`).
2. Asks what to call the camera window.
3. Shows a short summary and opens the live video. Press **`q`** to close it.

Any other answer to the first question exits the program.

## ▶️ Run it

```bash
pip install opencv-python
python3 camera.py
```
