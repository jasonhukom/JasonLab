# StudentScoreChecker

> Enter a student's name and their score for each subject, and get the **average** and an encouraging comment.

**Status:** ✅ Works

| File | Subjects asked |
| --- | --- |
| `Average.py` | 8, in English: Informatics, English, Art, PE, Religion, History, Sciences, Biology |
| `Average_Nilai.py` | 11, in Indonesian: IPA, Agama, PPKn, IPS, Bahasa Indonesia, Mandarin, PJOK, Matematika, Informatika, Bahasa Inggris, Art |

*Nilai* means "score".

## 💬 The comment

| Average | Message |
| --- | --- |
| 100 | Amazing Work |
| 90 – 99 | Good Job |
| 80 – 89 | Nice Work |
| 60 – 79 | Try better next time |
| below 60 | You did your best! |

Typing something that isn't a whole number just asks again.

## ▶️ Run it

```bash
python3 Average.py
```
