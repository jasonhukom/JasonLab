# Login · Get User Information

> **Gets User Information Program**: asks for a name, phone number and email address, then prints them back.

**Status:** ✅ Runs. It is a first draft, so the checks are basic.

- The phone number must be digits only (it asks again otherwise).
- The email prompt currently prints the word `prompt` instead of `Email Address:`, and the `@`/`.` check is very simple.

## ▶️ Run it

```bash
python3 get_user.py
```
