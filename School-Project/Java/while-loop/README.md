# while-loop

> A tiny demo of the difference between **`while`** and **`do … while`**.

**Status:** ✅ Works

1. The `while` loop prints `Halo dunia ke 0` … `Halo dunia ke 9` ("Hello world number …").
2. The `do … while` loop then runs **once** even though its condition is already false, printing `HELLO WORLD THE #10`. A `do … while` always runs at least once.

## ▶️ Run it

```bash
javac MyWhile.java
java MyWhile
```
