# CV.RPL2: Employee salary table (version 2)

> The second version of [CV.RPL](../CV.RPL/README.md): same salary table, with one extra first question.

**Status:** ✅ Works

The only difference: before asking how many employees you want to enter, it asks for an **array capacity** (*Kapasitas Data Array*), shows the capacity back (*Kapasitas Data Masih*), and then asks how many records to enter.

Everything else (grades A/B/C, spouse and child allowances, the Rupiah table) is identical. See [CV.RPL](../CV.RPL/README.md) for the details.

## ▶️ Run it

```bash
javac cv_rpl.java
java cv_rpl
```
