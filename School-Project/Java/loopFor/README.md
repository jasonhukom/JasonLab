# loopFor

> **Nested `for` loops** that print multiplication lines.

**Status:** ✅ Works

The outer loop counts `i` from 1 to 4, and the inner loop counts `j` down from 12 to 3 in steps of 3, printing `i x j = result`, for example `2 x 9 = 18`. The result is 16 lines.

The same output is produced with `while` loops in [`loopWhile`](../loopWhile/README.md).

## ▶️ Run it

```bash
javac loopFor.java
java loopFor
```
