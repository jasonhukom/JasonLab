# array-index

> Learning **arrays and indexes** in Java.

**Status:** ✅ Works

| File | What it does |
| --- | --- |
| `materi_array.java` | Asks how many values you want, then asks for each one and prints the array like `{3, 5, 8}` |
| `materi_array1.java` | Creates an array of 9, sets a few positions by index and prints the sum of two of them (`7 + 6 = 13`) |

*Materi* is Indonesian for "lesson material".

## ▶️ Run it

```bash
javac materi_array.java
java materi_array
```
