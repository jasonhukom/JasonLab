# loopWhile

> The **nested `while`-loop** twin of [`loopFor`](../loopFor/README.md): same multiplication lines, written with `while` instead of `for`.

**Status:** ✅ Works

`x` goes from 1 to 4. For each `x`, `y` goes 3, 6, 9, 12 and `x x y = result` is printed (16 lines). `y` is reset to 3 after each round of the outer loop.

## ▶️ Run it

```bash
javac loopWhile.java
java loopWhile
```
