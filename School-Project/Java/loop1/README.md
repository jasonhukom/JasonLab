# loop1

> Prints a **growing triangle of 1s**, with as many rows as you ask for.

**Status:** ✅ Works

Nested `for` loops: row 1 has one `1`, row 2 has two, and so on. After each run it asks `Again? (Y/n)`.

```text
Loop how many times?
4

1
11
111
1111
```

## ▶️ Run it

```bash
javac loop1.java
java loop1
```
