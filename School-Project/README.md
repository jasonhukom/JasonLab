# School-Project

> Schoolwork from Software Engineering (RPL/PPLG) classes at a vocational high school: Java exercises, PHP practicums and Python tasks.

| Folder | What's in it |
| --- | --- |
| [`Java/`](Java/README.md) | 11 classroom exercises: arrays, loops, odd/even, salary calculator, object-oriented programming |
| [`PHP/`](PHP/README.md) | *Praktikum Pemrograman Web*: seven PHP lab sessions |
| [`Python/`](Python/README.md) | Webcam viewer, user-info form, score averages and a typing speed test |

> Many variable names, prompts and comments are in **Indonesian** (for example *masukan* = enter, *nilai* = score, *gaji* = salary, *ganjil/genap* = odd/even).
