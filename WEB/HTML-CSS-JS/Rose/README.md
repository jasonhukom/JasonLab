## 🌹 What is this?

An animated web page where a rose **blooms from code**. A glass-style card labelled *Love.css* shows a loading bar and a **Tap to Bloom** button; pressing it grows a 3D-looking rose (stem, thorns, leaves, petals) and finishes with falling petals and a closing message.

It is built with plain HTML, CSS and JavaScript.

## 📁 Files

| File | Purpose |
| --- | --- |
| `index.html` | Page structure: start card, scene, rose parts |
| `style.css` | All the look and the animations (about 650 lines) |
| `script.js` | Loading bar, the *Tap to Bloom* sequence, falling petals |

## ▶️ How to use

Open `index.html` in a browser. An internet connection is needed for the Google Fonts (Playfair Display, Inter, Fira Code); without it the page falls back to default fonts.
