# Tragedi-9-11

> **A school web page (in Indonesian) about the 11 September 2001 attacks.**

## 📰 What is this?

A static informational page, written in Indonesian, as a web-programming exercise. It covers the 9/11 attacks: a title and photo, an introduction, a list of key points, a general summary, a comments section and an "about this website" part.

## ✨ Features

- **Dark mode** button in the navigation bar toggles the page theme.
- **Feedback button** that shows a thank-you pop-up.
- Responsive picture-and-text layout built with a CSS grid.

## 📁 Files

| File | Purpose |
| --- | --- |
| `index.html` | The page content (in Indonesian) |
| `style.css` | Layout, colours and dark-mode styles |
| `script.js` | Dark-mode toggle and the feedback pop-up |
| `911.webp`, `911-landscape.jpg` | Page images |
| `night-mode-black.png` | Icon for the dark-mode button |

## ▶️ How to use

Open `index.html` in a browser. No server or install needed.
