# Animation-WEB

> A starting point for an **animated menu bar** ("Menu UI"): five buttons, a moving highlight border and an SVG area.

**Status:** 🚧 Scaffolding. The HTML structure and a few CSS variables are in place, but the buttons are still `...`, the SVG is empty, the script block is empty, and the CSS has typos (`margin: @`, `box_sizing`), so nothing animates yet.

## 📁 Files

| File | Purpose |
| --- | --- |
| `index.html` | A `<menu>` with five buttons, a border element and an SVG container |
| `style.css` | Colour and animation-duration variables, page centring, background colour |
