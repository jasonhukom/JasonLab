# Flower-Maker · Build Your Bouquet

> Pick flowers and **arrange them however you like**: click a flower to add it, then drag it around.

**Status:** ✅ Works

## 🌸 How to use

1. Click one of the flower buttons: 🌹 rose, 🌷 tulip, 🌻 sunflower, 🌼 daisy or 🌸 cherry blossom.
2. A flower appears in the middle of the bouquet area.
3. **Drag** any flower (mouse or touch) to place it.
4. Add as many as you like.

## 📁 Files

| File | Purpose |
| --- | --- |
| `index.html` | Page: header, bouquet area and flower picker |
| `style.css` | Look and layout |
| `script.js` | Creates the flowers and makes them draggable using pointer events |

## ▶️ Open it

Open `index.html` in a browser.
