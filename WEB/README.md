# WEB

> Web projects: static pages with HTML/CSS/JavaScript, and a PHP calculator.

| Folder | What's in it |
| --- | --- |
| [`HTML-CSS-JS/`](HTML-CSS-JS/README.md) | Five front-end projects: a menu animation, a Bible reading calendar, a flower bouquet maker, a blooming rose and a school page |
| [`PHP/`](PHP/README.md) | **PHPulator**: a calculator page written in PHP |

## ▶️ Running

- **HTML/CSS/JS:** just open `index.html` in a browser.
- **PHP:** run `php -S localhost:8000` in the folder, then open `http://localhost:8000/` plus the file name.
