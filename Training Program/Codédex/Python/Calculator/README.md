# Area Calculator

> Pick a shape, enter its measurements, and get its **area**.

**Status:** ✅ Works

| Choice | Shape | You enter | Formula |
| --- | --- | --- | --- |
| 1 | Triangle | height, base | ½ × h × b |
| 2 | Rectangle | length, width | l × w |
| 3 | Square | side | s² |
| 4 | Circle | radius | π × r² |
| 5 | Quit | – | – |

Whole-number results are shown without a decimal point (`12` rather than `12.0`).

## ▶️ Run it

```bash
python3 calculator.py
```
