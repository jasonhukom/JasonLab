# Rock Paper Scissors Lizard Spock

> The five-move version of rock-paper-scissors made famous by *The Big Bang Theory*, played against the computer.

**Status:** ✅ Works

## 🎮 How to play

Type a number to choose your move; the computer picks one at random and the result is printed.

| Number | Move |
| --- | --- |
| 1 | ✊ Rock |
| 2 | ✋ Paper |
| 3 | ✌️ Scissors |
| 4 | 🦎 Lizard |
| 5 | 🖖 Spock |

It plays round after round. **Type anything that isn't a number (like `q`) to quit.** Numbers outside 1–5 are ignored.

## ▶️ Run it

```bash
python3 rock_paper_scissors.py
```
