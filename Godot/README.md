# Godot

> Game-engine experiments with [Godot](https://godotengine.org/) 4.4.

| Project | What it is | Status |
| --- | --- | --- |
| [`godot-game/`](godot-game/README.md) | Empty Godot project (just the default icon) | 🚧 blank starter |
| [`the-good-book/`](the-good-book/README.md) | 2D pixel-art scene with an animated earth, a character and a text label | 🚧 early prototype |

## ▶️ How to open

1. Download **Godot 4.4** (the standard version, not .NET) from [godotengine.org](https://godotengine.org/download).
2. In the Project Manager click **Import**, choose the project's `project.godot` file, then **Import & Edit**.
3. Press **F5** to run the project (**F6** runs the scene that's currently open).

Both projects use the *Forward Plus* renderer.
