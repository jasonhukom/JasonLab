# C

> First experiments in C.

| Project | What it does |
| --- | --- |
| [`creeper/`](creeper/README.md) | Prints a very long Minecraft creeper scream |
| [`jason/`](jason/README.md) | Prints a name three times |

## ▶️ Compile and run

You need a C compiler (`gcc` or `clang`; on Windows, MinGW-w64 works).

```bash
cd creeper
gcc creeper.c -o creeper
./creeper
```
