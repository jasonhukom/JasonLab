# creeper

> Prints **CREEEEE…PER**, the sound a Minecraft creeper makes right before it explodes.

**Status:** ✅ Works

A one-line `printf` program, written as a joke while learning C.

## ▶️ Run it

```bash
gcc creeper.c -o creeper
./creeper
```

Output: a very long `CREEEEE…PER` followed by a newline.
