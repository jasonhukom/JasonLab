# Bubble-Sort

> Type in some numbers and get them back **sorted from smallest to biggest**, using the bubble sort algorithm.

**Status:** ✅ Works

## ⚙️ How it works

1. Asks for the length of the array.
2. Asks for each number. If you type something that isn't a whole number it complains (with a cheeky message) and asks again.
3. Repeatedly walks through the array, swapping neighbours that are in the wrong order (bubble sort).
4. Prints `SORTED` followed by the numbers, one per line.

## ▶️ Run it

```bash
javac bubblesort.java
java bubblesort
```
