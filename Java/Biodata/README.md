# Biodata

> Prints a **personal biodata sheet** to the console.

**Status:** ✅ Works

Two sections written with `System.out.println`: **PERSONAL** (name, contact, personal details, languages known) and **EDUCATIONAL BACKGROUND** (school and major). File name `Lat20250115.java`: *Lat* is short for *latihan*, Indonesian for "exercise".

## ▶️ Run it

```bash
cd src
javac Lat20250115.java
java Lat20250115
```
