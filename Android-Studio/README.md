# Android-Studio

> Two small Android apps built with Android Studio.

| Project | What it is | Language | Status |
| --- | --- | --- | --- |
| [`My-App/`](My-App/README.md) | Jetpack Compose starter with a bottom/side navigation bar | Kotlin | 🚧 starter template |
| [`Nomor-Telp/`](Nomor-Telp/README.md) | Form: type a phone number, pick its type, see it in a pop-up | Java | ✅ works |

## ▶️ How to open and run

1. Install [Android Studio](https://developer.android.com/studio).
2. **File → Open…** and choose the project folder (`My-App` or `Nomor-Telp`, not this one).
3. Wait for the Gradle sync to finish.
4. Pick an emulator or a phone with USB debugging, then press **Run ▶**.

Both apps target Android SDK 36 and use Java 11 compatibility.
